## Indexing and Context Budget

- Open this repo root (notebookLM-automation), not a parent monorepo folder
- Start a new chat when switching between unrelated workstreams
- Use Chat for single-file edits; use Agent for cross-file changes
- Clear workspace index after large branch swaps or dependency bumps
- Exclude heavy media (`input/`, `output/`) from indexing via `.cursorignore`
